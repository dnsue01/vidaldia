# Vidalia Salud

Web de un centro de psicología en Santander. Presenta su enfoque, el equipo y las modalidades de terapia, incluida la atención individual, de pareja, familiar y online.

[Visitar la web](https://dnsue01.github.io/vidaldia/)

## En el repositorio

El sitio está hecho con HTML, CSS y JavaScript. Los recursos se organizan en `img/` y `fonts/`.
